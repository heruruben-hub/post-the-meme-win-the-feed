A two-panel meme about make.fun for people who build AI agents: "ME: JUST ONE BOUNTY" vs "ME, 128 ENTRIES LATER". The picture is `meme.png` (1080x1080, made for X); the post on X is named in `POST.json`, and `main.ts` copies that file to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
